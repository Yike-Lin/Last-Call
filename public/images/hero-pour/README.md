# Hero pour assets (v1)

阶段 1 产出的首版酒杯素材，暂不接入页面。

- `glass-empty-v1.png`：透明底、空杯、三块冰。
- `glass-filled-v1.png`：透明底、约 70% 液位的琥珀酒液版本。
- `orange-peel-v1.png`：透明底、短 C 形橘子皮。

这些文件来自同一轮视觉方向生成，先用于确认材质、色调和构图。空杯与满杯的冰块细节仍需要在阶段 2 的蒙版接入时做一次像素对齐检查；如果出现明显错位，再回到素材阶段做同构图修订，不直接拿错位版本上线。
